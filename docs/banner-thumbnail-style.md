# Grailwright Banner and Thumbnail Style

Use this as the default visual treatment for Grailwright promotional art.

## Typography

- **Font:** Metal Mania
- **Case:** All caps
- **Shape:** Slight vertical stretch if needed
- **Spacing:** Tight, but never let letters touch
- **Finish:** Add scratches with a grunge or dry-brush layer mask
- **Edge:** Use a subtle black shadow or 2-3 px dark outline

Keep distressing uneven and preserve the main letter shapes so titles remain readable at thumbnail size.

## Colours

| Use | Colour |
| --- | --- |
| Background | `#050505` |
| Primary text / bone white | `#CBBAA4` |
| Secondary text / blood red | `#850B02` |
| Shadow / outline | `#010101` |

Default to bone white for the first or identifying line and blood red for the second or action line. Use bright red only for small highlights.

## Quick Recipe

1. Place large, centered Metal Mania text over a near-black background.
2. Set the main line in bone white and the emphasis line in blood red.
3. Apply restrained scratches and chipped edges with a layer mask.
4. Add a thin black edge for separation.
5. Check readability at the final thumbnail size.

Version 1.1.3
Moved the hold-to-battlecry input from Toggle Weapon to the game's remappable Take All Items action, while leaving normal container looting authoritative when a container is open.
Advanced the config schema from 6 to 7 because HoldToggleWeaponForBattlecry was replaced by HoldTakeAllItemsForBattlecry for the new input behavior.

Version 1.1.2
Added a separate indoor battlecry hearing range multiplier that defaults to four times each hostile NPC's normal maximum hearing range; the existing three-times multiplier now applies outdoors.
Advanced the config schema from 5 to 6 because BattlecryAggroRangeMultiplier now controls outdoor challenges while the new IndoorBattlecryAggroRangeMultiplier controls interiors, caves, and roofed spaces.
Kept the fresh outdoor default when importing older backups because the existing hearing range setting previously applied to every environment.

Version 1.1.0
Reduced the fresh-config random pitch variation from 0.25 to 0.15 semitones.
Advanced the config schema from 4 to 5 because the RandomPitchSemitones default changed. Existing customized values remain eligible for conservative recovery.
Extended geometry-sampled battlecry acoustics to full interiors, caves, and roofed spaces with dedicated horizontal, elevated, lowered, floor, and ceiling measurements.
Added room-shape classification for open-roof structures, corridors, small and medium rooms, caves, large halls, and large caverns, then derived reverb decay, density, filtering, and early/late balance from the measured space.
Limited discrete interior reflection taps to surfaces far enough away to produce a natural repeat, so compact rooms use dense early reverb while large spaces can return up to three distance-timed 3D echoes.
Kept the proven outdoor tuning unchanged and retained the fixed indoor or roofed preset whenever geometry is too sparse or sampling fails.

Version 1.0.9
Replaced the fixed outdoor battlecry response with a one-shot 24-direction acoustic probe that measures nearby terrain, vegetation, structures, and overhead surfaces only when a cry plays.
Added up to three filtered 3D reflection taps with timing derived from measured round-trip distance, while open terrain now receives a much drier diffuse tail and enclosed outdoor spaces retain stronger ambience.
Kept the game's interior and roof-volume classification authoritative, retained the fixed indoor response, and preserved the previous outdoor preset as a safe fallback if geometry sampling fails.

Version 1.0.8

Advanced the config schema from 3 to 4 because the BattlecryAggroRangeMultiplier default changed. Existing customized values remain eligible for conservative recovery.

Version 1.0.0

Added gender-aware random battlecries from pools of up to 10 custom WAV files per gender, with placeholder slots and existing pitch, random-pitch, and volume tuning.

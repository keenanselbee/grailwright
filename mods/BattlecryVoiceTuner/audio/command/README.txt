Summon command filename contract
================================

Keep every command WAV directly in this folder and use:

summon_{gender}_{command}_{index}.wav

Supported genders are male and female. Supported commands are attack, hold,
follow, guard, bulwark, and hunt. Indices start at 0 and remain consecutive
within each pool. Each gender-and-command pool keeps its own recent-playback
history.

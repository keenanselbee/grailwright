[center][color=#C94A4A][size=6]Enemy Respawn Control[/size][/color]
[i]Control enemy respawn timing with in-game/weather-time presets.[/i][/center]

[line]

Enemy Respawn Control is a standalone BepInEx 5 Mono plugin for [b]Tainted Grail: The Fall of Avalon[/b]. It remembers spawners after their spawned enemies are killed and blocks future spawn attempts until the configured delay has elapsed.

The default [b]Slow72Hours[/b] preset means 3 in-game/weather days when [b]UseWeatherTime[/b] is enabled. This is intended to behave sensibly with TimeMod and other day-night speed changes while keeping the world from feeling permanently empty.

[line]

[heading][color=#C94A4A][size=5]What It Does[/size][/color][/heading]
[list]
[*]Guards cleared spawners after their spawned enemies are killed.[/*]
[*]Blocks respawn checks and direct spawn attempts until the configured delay has elapsed.[/*]
[*]Uses in-game/weather time by default, so day-night speed changes are respected.[/*]
[*]Offers presets from very fast respawns to indefinitely blocked cleared spawners.[/*]
[*]Includes diagnostics for spawner lock creation, blocked gate names, allowed spawn attempts, cleanup, and lock expiry decisions.[/*]
[/list]

[line]

[heading][color=#C94A4A][size=5]Presets[/size][/color][/heading]
[code=plaintext]
VeryFast2Hours  | 2 hours
Fast6Hours      | 6 hours
Default24Hours  | 24 hours
Slow72Hours     | 72 hours
VerySlow168Hours| 168 hours
Custom          | CustomRespawnHours
Disabled        | block cleared spawners indefinitely
[/code]

[line]

[heading][color=#C94A4A][size=5]Configuration[/size][/color][/heading]
Start the game once to generate:

[code]
BepInEx/config/ks.tgfoa.enemy-respawn-control.cfg[/code]

Common entries:

[code]
Enabled = true
RespawnMode = Slow72Hours
CustomRespawnHours = 168
UseWeatherTime = true
Diagnostics = false[/code]

Version 1.0.2 adds broader spawn gates for enemies that do not use the vanilla cooldown path. If you are testing stubborn spawns such as skeletons, enable [b]Diagnostics[/b] and look for gate names like [b]can-spawn[/b], [b]is-valid-state[/b], [b]should-spawn[/b], [b]spawn-prefab-internal[/b], or [b]spawned-location-cleanup[/b].

[line]

[heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with Vortex as a [b]BepInEx plugin[/b], or place the plugin folder here:

[code]
BepInEx/plugins/EnemyRespawnControl/EnemyRespawnControl.dll[/code]

[heading][color=#C94A4A][size=5]Notes[/size][/color][/heading]
Disable or remove older RespawnTimer-style mods while testing Enemy Respawn Control. If an area still respawns too quickly, enable [b]Diagnostics[/b] and check [b]BepInEx/LogOutput.log[/b] for spawner lock, blocked gate, and cleanup messages.

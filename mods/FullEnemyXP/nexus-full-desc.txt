[center][color=#C94A4A][size=6]Full Enemy XP - No Overlevel Penalty[/size][/color]
[i]Keep enemy kill XP steady when you outlevel the fight.[/i][/center]

[line]

[b]Full Enemy XP[/b] removes the vanilla enemy overlevel XP penalty in [b]Tainted Grail: The Fall of Avalon[/b]. Enemies below your level keep giving their normal enemy kill XP instead of being reduced by the level gap.

[heading][color=#C94A4A][size=5]Features[/size][/color][/heading]
[list]
[*][b]Full overlevel rewards:[/b] Raise the enemy-level multiplier for lower-level kills back to full XP by default.[/*]
[*][b]Vanilla foundations preserved:[/b] Keep enemy base XP, XP tiers, New Game Plus bonuses, the Hero kill multiplier, and the global XP multiplier intact.[/*]
[*][b]Focused scope:[/b] Leave same-level and higher-level rewards, XP-blocked enemies, summons, non-player kills, quests, exploration, crafting, and proficiency XP unchanged.[/*]
[*][b]Configurable floor:[/b] Lower the minimum multiplier if you prefer partial vanilla falloff instead of full rewards.[/*]
[*][b]Safe diagnostics:[/b] Use dry-run logging to inspect the proposed reward calculation without changing actual XP.[/*]
[/list]

[line]

[heading][color=#C94A4A][size=5]Configuration[/size][/color][/heading]
Config file:

[code]BepInEx/config/ks.tgfoa.full-enemy-xp.cfg[/code]

Main settings:

[code]
Enabled = true
MinimumOverlevelXPMultiplier = 1
[/code]

The default value of [b]1[/b] means full enemy XP when you are above the enemy XP level. Lower values allow partial vanilla falloff.

[b]Diagnostics[/b]

For testing, enable:

[code]
Diagnostics = true
DryRun = true
[/code]

Dry run logs what the mod would change without modifying the actual XP reward. Diagnostic lines include the enemy name, Hero level, enemy XP level, base XP, vanilla level multiplier, applied multiplier, and estimated XP before the game's global XP multiplier.

[line]

[heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with Vortex as a [b]BepInEx plugin[/b], or place the plugin folder here:

[code]BepInEx/plugins/FullEnemyXP/FullEnemyXP.dll[/code]

[line]

[heading][color=#C94A4A][size=5]Updating[/size][/color][/heading]
Incompatible config updates create a backup and generate current defaults. Some supported settings are automatically carried over.

FoA Mod Manager's final [b]Import Previous Settings[/b] tab shows the current and available backup schemas. Toggle the import action to restore compatible customized settings. Restart the game after importing.

[heading][color=#C94A4A][size=5]Compatibility[/size][/color][/heading]
Full Enemy XP patches the enemy death XP calculation. It should be compatible with mods that add separate bonus XP after kills, but may overlap with mods that replace or heavily transpile enemy death XP rewards.

[b]Optional diagnostics:[/b] [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/247]Grail Floating Text[/url] can show critical load errors in-game, with details in the BepInEx log.

Version 1.5.0
Standardized stale config schema reset handling with the other Grailwright mods, including timestamped pre-schema backups and legacy General-section schema detection.

Version 1.4.9
Fixed stale config schema regeneration so upgrading from older configs no longer aborts startup after backing up the old cfg.

Version 1.4.8
Added built-in XP gain floating text takeover using the new experience icon, White color group, and Short duration bucket.
Added API v5 XP gain claims so integrations can style the next XP stat gain they trigger without producing a duplicate generic XP entry.
Added the built-in experience and corpse icon IDs and mapped Blood Magic Expansion corpse XP claims into the Red color group by default.
Raised ConfigSchemaVersion to 9 so the XP takeover, White group, and new icon defaults regenerate.

Version 1.4.7
Added API v4 TryShowEvent calls with stable event IDs and named duration buckets.
Added configurable VeryShort, Short, Medium, Long, and VeryLong duration buckets, with event callbacks defaulting to Medium.
Added editable color groups with configurable event ID lists and moved Killing Blow Mastery into the Red group by default.
Changed default Scale to 1 and BaseCenterY to 0.25 while keeping DefaultDurationSeconds at 2.
Raised ConfigSchemaVersion to 8 so the new layout, duration bucket, and color group defaults regenerate.

[center][color=#C94A4A][size=6]Grail Floating Text[/size][/color]
[i]A shared floating text overlay for events and mod messages.[/i][/center]

[line]

[b]Grail Floating Text[/b] gives players and mod authors one shared overlay for short rewards, status updates, events, system notices, and debug messages.

It gives mod authors one standard place to send short reward, status, event, system, and debug messages instead of each mod drawing its own text stack. Messages can include shared tinted icon masks, appear near the configured screen position, pop in briefly, push older still-visible messages upward, and fade out cleanly.

For players, that means less overlapping HUD text. For mod authors, it means a small reflection-friendly API that can be used as an optional dependency without forcing a hard install requirement.

[heading][color=#C94A4A][size=5]Features[/size][/color][/heading]
[list]
[*][b]One shared message stack:[/b] Keep active mod text organized with smooth pop-in, upward movement, priority sorting, duplicate suppression, and in-place status updates.[/*]
[*][b]Useful game-event notices:[/b] Optionally show rest duration, block and parry feedback, encumbrance, cleared locations, pickpocket results, bounties, weak spots, sneak attacks, and Wyrd events.[/*]
[*][b]Readable built-in presentation:[/b] Use painterly icons, protected texture filtering, configurable colors and shadows, and font modes that can follow the game's Accessibility choice.[/*]
[*][b]Detailed player control:[/b] Configure message categories, position, scale, width, spacing, timing, opacity, animation, icons, and the maximum visible stack.[/*]
[*][b]Source-aware behavior:[/b] Control enabled state, throttling, duration, and diagnostics per integration while keeping XP consolidation isolated by source.[/*]
[*][b]Mod-author API:[/b] Send immediate or deferred reflection-friendly messages with stable event IDs, styles, categories, priorities, collapse keys, and optional icons.[/*]
[*][b]Quick-wheel panels:[/b] Give integrations a reusable right-anchored two-column surface with GFT fonts, colors, icons, and tooltip-aware opacity.[/*]
[/list]

[/list]

Grail Floating Text itself listens only to low-frequency or explicitly fired game events plus the vanilla XP gain announcer. XP batching never changes the visible entry or restarts its timer: queued compatible gains receive a fresh full display cycle when their turn begins. Generic XP never merges with mod-claimed XP, and claimed XP requires the same source-specific key and presentation. GFT still avoids duplicating native advanced notification buffers such as items, proficiency, quests, objectives, recipes, fish, journal unlocks, location discovery, and hero level-up. KS Wyrd Hunt Addon remains responsible for Wyrd Scent wording, hunt/safety interpretation, and scent meter replacement behavior.

[heading][color=#C94A4A][size=5]Message Types[/size][/color][/heading]
Mods can send messages with a category, priority, style, icon ID, and optional collapse key.

[code]
| Category | Intended use                                      |
|----------|---------------------------------------------------|
| General  | Ordinary mod events                               |
| Combat   | Combat feedback                                   |
| Reward   | XP, loot, progress, or achievement-style feedback |
| Status   | Changing state such as Wyrd Scent                 |
| System   | Setup, compatibility, or availability messages    |
| Debug    | Diagnostic messages, hidden by default            |
[/code]

[code]
| Priority | Behavior                                                  |
|----------|-----------------------------------------------------------|
| Low      | Quiet messages, affected by source throttling             |
| Normal   | Default message priority                                  |
| High     | Bypasses source throttling and sorts ahead of normal text |
| Critical | Highest priority and critical styling fallback            |
[/code]

[b]Collapse keys[/b] are for status messages that should update in place. For example, Wyrd Hunt Addon uses one stable collapse key for Wyrd Scent status text, so changing scent states replace the old visible status line instead of building a stack of stale states.

[heading][color=#C94A4A][size=5]For Mod Authors[/size][/color][/heading]
Declare Grail Floating Text as a soft dependency:

[code]
ks.tgfoa.grail-floating-text
[/code]

Resolve the API by reflection:

[code]
GrailFloatingText.NotificationApi
[/code]

API v9 adds a separate persistent panel surface:

[code]
GrailFloatingText.QuickWheelPanelApi
TrySet(sourceId, leftTitle, leftSubtitle, leftTexts, leftIconIds, leftStyles, rightTitle, rightSubtitle, rightTexts, rightIconIds, rightStyles, opacity, tooltipOpacity, fadeSeconds, rightOffset, topOffset, scale)
SetTooltipActive(sourceId, active)
Clear(sourceId)
[/code]

The caller owns panel lifetime and row limits. GFT owns rendering, font resolution, style colors, built-in icons, position, and the configured fade between normal and tooltip-active opacity.

[b]Adding a compatibility detection:[/b] verify the exact loaded DLL or enabled setting in your own mod, then submit one concise [b]System[/b]/[b]Critical[/b] event with the [b]warning[/b] icon and [b]OnMainMenu[/b] delivery. Use a stable event ID, log the exact evidence to [b]BepInEx/LogOutput.log[/b], and do not guess or change the other mod automatically.

[code]TryShowEvent(PluginGuid, "compat-other-mod", conciseText, "Warning", "System", "Critical", "", "warning", "System", "OnMainMenu", 0.25f, 1.0f)[/code]

Fade-in stays at [b]DefaultFadeSeconds[/b]. Fade-out scales with total message duration, from 60% to 200% of that baseline and never longer than half the message lifetime. With the defaults, Medium fades out over 0.25 seconds and System over 0.5 seconds.

API v7 deferred event call shape:

[code]
TryShowEvent(sourceId, eventId, text, style, category, priority, collapseKey, iconId, durationBucket, deliveryPoint, fadeSeconds, opacity)
[/code]

Delivery points are [b]Immediate[/b], [b]OnMainMenu[/b], and [b]OnLoad[/b]. OnMainMenu waits for the initialized interactive title view. OnLoad waits for an initialized hero and world, completed location/HLOD loading, a dismissed loading screen, a completed camera transition, no covering fullscreen video or cutscene, and a focused game window. Deferred messages persist until shown, and their duration begins on their first eligible rendered frame.

API v8 consolidated XP claim call shape:

[code]
TryClaimConsolidatedXpGain(sourceId, eventId, consolidationKey, textFormat, style, category, priority, iconId, durationBucket, expectedAmount, fadeSeconds, opacity)
[/code]

Call it immediately before changing hero XP. GFT combines only matching keys from the same source and presentation; use [b]{xp}[/b] or [b]{amount}[/b] in the format and a different key for every meaning that must remain separate. Fall back to the v6 claim when v8 is unavailable.

API v6 one-shot XP claim call shape:

[code]
TryClaimXpGain(sourceId, eventId, text, style, category, priority, iconId, durationBucket, expectedAmount, fadeSeconds, opacity)
[/code]

The next matching XP stat gain uses the claimed text/event/style/icon instead of the generic XP event. API v6 claims remain separate.

API v4 event-aware call shape:

[code]
TryShowEvent(sourceId, eventId, text, style, category, priority, collapseKey, iconId, durationBucket, fadeSeconds, opacity)
[/code]

Duration buckets are [b]VeryShort[/b], [b]Short[/b], [b]Medium[/b], [b]Long[/b], [b]VeryLong[/b], and [b]System[/b]. Their defaults are 3, 3.5, 4, 4.5, 5, and 10 seconds respectively. System is intended for startup, config-reset, and load-time error messages. Empty or unknown bucket names use [b]Medium[/b].

API v3 call shape:

[code]
TryShow(sourceId, text, style, category, priority, collapseKey, iconId, durationSeconds, fadeSeconds, opacity)
[/code]

API v2 calls still work:

[code]
TryShow(sourceId, text, style, category, priority, collapseKey, durationSeconds, fadeSeconds, opacity)
[/code]

[heading][color=#C94A4A][size=5]Updating[/size][/color][/heading]
Incompatible config updates create a backup and generate current defaults. Some supported settings are automatically carried over.

FoA Mod Manager's final [b]Import Previous Settings[/b] tab shows the current and available backup schemas. Toggle the import action to restore compatible customized settings. Restart the game after importing.

[heading][color=#C94A4A][size=5]Compatibility[/size][/color][/heading]
Grail Floating Text draws its own IMGUI overlay when another mod queues a message, when an enabled built-in default game event fires, or when the vanilla XP announcer reports an XP gain. It does not modify combat, quests, saves, items, enemies, or stat values. Built-in event notices are event-driven and throttled where needed; they do not poll combat, inventory, quest, or save state.

[b]Optional diagnostics:[/b] Integrated mods can show critical load errors in-game, with details in the BepInEx log.

If messages are too frequent, use the category toggles or the per-source sections in the config. If messages are missing, make sure [b]Enabled[/b] is true, the relevant category is enabled, and the sending mod is installed and configured to use Grail Floating Text.

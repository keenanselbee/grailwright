Version 0.2.2
Added a HalfSpeedBonuses combat mode that retains exactly half of each positive Better Movement walk, jog, sprint, and swim bonus; for example, 1.20x becomes 1.10x.
Kept every transition into, out of, or between speed tiers at one full second instead of allowing the half-strength tier to complete in half a second.

Version 0.2.1
Replaced the binary combat speed setting with an off-by-default Combat Override Mode: Off, SpeedBonuses, MobilityAdvantages, or FullVanilla.
Expanded one-second combat speed blending to positive walk, jog, sprint, and swim multipliers while preserving native speed, penalties, and other mods' modifiers.
Added a MobilityAdvantages tier that restores vanilla sprint directions, walking penalties, dash permissions, encumbrance restrictions, and dash limits during combat.
Added a FullVanilla tier that transiently suppresses every Better Movement patch without writing to its config, explicitly restores the parent's unguarded sprint stamina and FOV paths, and changes state only after active movement actions finish.
Advanced ConfigSchemaVersion from 3 to 4 because the old DisableSpeedBonusesInCombat boolean was removed and replaced by the CombatOverrideMode enum; the retired setting is not migrated and the new mode defaults to Off.

Version 0.1.8
Added an off-by-default Disable Speed Bonuses In Combat setting that removes only Better Movement's positive walk, jog, and sprint multipliers during combat.
Blended the combat correction in and out over one second while preserving native movement speed, other mods' modifiers, and Better Movement speed penalties.

Version 0.1.7
Removed numeric prefixes from the generated config sections and added explicit FoA Mod Manager ordering for every visible setting.
Advanced ConfigSchemaVersion from 2 to 3 because settings moved to the clean General, Audio, Terrain Detection, and Diagnostics sections; this one-time cleanup regenerates defaults instead of guessing mappings from the retired section names.
Kept Diagnostics penultimate and Import Previous Settings last in the config menu.

Version 0.1.6
Changed the FoA Mod Manager config-menu title to BetterMovement Addon so it groups with the parent mod.

Version 0.1.5
Removed the KS prefix from the FoA Mod Manager config-menu title.

Version 0.1.4
Raised ConfigSchemaVersion from 1 to 2 because the default Volume changed from 0.45 to 0.40; untouched old defaults now regenerate at 0.40 while compatible customized settings remain eligible for conservative recovery.

Version 0.1.3
Updated the successful startup message to describe replaceable custom slide audio instead of referring to the included Foley as placeholders.

Version 0.1.2
Reworked puddle loops and transients as a 70 percent ground and 30 percent water blend so wet slides retain clear ground friction instead of sounding like stream wading.
Lowered the default overall slide-audio volume from 0.45 to 0.40. Existing saved configurations retain their current value.

Version 0.1.1
Replaced the synthetic development placeholders with 66 edited terrain Foley assets from the licensed Footsteps: Full Bundle.
Added two seamless loop, start, and stop variants for each of the eleven supported terrain categories.
Standardized runtime audio as mono 48 kHz 16-bit PCM with controlled loudness, peak headroom, and measured loop boundaries.

Version 0.1.0
Added terrain-aware FMOD slide audio for Better Movement slide begin, continuation, terrain transitions, cancellation, and ending.
Added native terrain splatmap, mesh surface, and shallow-water detection without patching Immersive Footsteps' playback route.
Added replaceable loop, start, and stop WAV discovery for eleven native terrain categories.
Added lightweight synthetic placeholder audio for development testing while final licensed Foley is selected.
Added configurable volume, speed response, pitch response, crossfade timing, attenuation distance, terrain polling, and diagnostics.

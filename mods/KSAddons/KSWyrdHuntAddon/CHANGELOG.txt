Version 1.4.1
Added one-shot Wyrd Hunt tuning presets: Sparse, Stalker, CursedNight, and Default.
Selecting a preset now writes Wyrd Hunt's hunt/threat settings, saves them, records the last applied preset, and resets the selector to Custom so manual edits remain active.
Raised ConfigSchemaVersion to 5 so the new preset entries generate cleanly.

Version 1.4.0
Updated Grail Floating Text Wyrd Scent status routing to API v4 with the wyrd-hunt-status event ID and the Medium duration bucket.
Removed the local hardcoded floating-text display duration and now lets Grail Floating Text use its medium/default duration.

Version 1.3.9
Added Grail Floating Text Wyrd icon routing for Wyrd Scent status notifications when the icon-capable API is available.
Kept fallback compatibility with older Grail Floating Text versions that do not expose icon IDs.

Version 1.3.8
Changed the default NotificationsOnly meter replacement: if Grail Floating Text is installed, the parent Wyrd Scent meter is hidden by default.
Documented Grail Floating Text as an optional soft dependency for shared status text.

Version 1.3.7
Updated Grail Floating Text status messages to API v2 with Status category and a collapse key.

Version 1.3.6
Updated optional Wyrd Scent status text integration for Grail Floating Text.
Changed the optional dependency lookup to ks.tgfoa.grail-floating-text.

Version 1.3.5
Moved Wyrd Hunt status text to the optional Grail Floating Text shared stack.
Removed the local compact overlay renderer and overlay layout settings.
Raised ConfigSchemaVersion to 4 so old local overlay settings are backed up and removed from regenerated configs.
Kept the parent Wyrd Scent meter visible when Grail Floating Text is missing.

Version 1.3.3
Moved optional hunt randomizer, mixed-pack, role-summary, and pressure-intent hooks onto individually guarded patch calls so a changed optional Wyrd Hunt hook cannot stop HUD notifications, meter hiding, or startup completion.
Added a startup summary for optional hunt patch availability while keeping ConfigSchemaVersion 3.

Version 1.3.2
Fixed startup patching so optional loading UI hooks cannot prevent core Wyrd Scent meter, position, and notification patches from applying.
Kept ConfigSchemaVersion 3 because no settings or defaults changed.

Version 1.3.1
Changed default compact Wyrd Hunt notifications to cleaner event text: Wyrd Scent stage names, Safe from Wyrdness, and Exposed to Wyrdness.
Added Show Scent Number so users can append the current scent value to stage-change notifications.
Raised ConfigSchemaVersion to 3 so the cleaner notification defaults apply.

Version 1.3.0
Added compact Wyrd Scent status notifications in the same style as Killing Blow Mastery's compact overlay.
Added Scent Meter Mode with NotificationsOnly as the default, AutoHide for the older meter-hiding behavior, and Parent for Wyrd Hunt's native meter behavior.
Improved AutoHide loading-screen hiding by tracking scene changes and loading UI lifecycle events only when the scent meter can actually draw.
Raised ConfigSchemaVersion to 2 so the new HUD and notification defaults apply cleanly.

Version 1.2.2
Added ConfigSchemaVersion 1 so older or unversioned configs are backed up and regenerated with clean defaults.
Kept Wyrd Scent meter hiding, randomized hunts, and mixed-pack behavior unchanged.

Version 1.2.1
Allowed Wyrdspirit to appear as a prioritized mixed-pack sidecar.
Added a special Wyrdspirit sidecar rule: when selected, Wyrdspirit spawns as a random 1-4 spirit cluster.
Reweighted sidecars so weaker enemies are favored while same-tier and same-family picks are much less likely.

Version 1.2.0
Added optional mixed hunt packs for randomized Stalking, Hunter, Pursuit, and Marked hunts.
Extra pack mates are selected from the same hunt layer, must be same-or-lower tier than the primary target, and avoid duplicate templates.
Contact hunts remain single-only, hard pack mates are disabled by default, and extras are pressure enemies rather than official hunt objectives.

Version 1.1.1
Added optional Wyrd Scent meter hiding for title, loading, startup, and other non-hero scenes.
Kept existing safe-from-Wyrdness hiding, meter offsets, and Wyrd Hunt spawn randomization behavior unchanged.

Version 1.1.0
Companion addon for Wyrd Hunt 0.4.65.
Preserves HUD tweaks that hide the Wyrd Scent meter when safe from Wyrdness and reposition the meter with offsets.
Adds configurable weighted random native hunt spawns so the active hunt target matches the monster that actually spawns.
Keeps settings in ks.tgfoa.wyrd-hunt-addon.cfg and is intended as a companion tuning addon for the parent mod.

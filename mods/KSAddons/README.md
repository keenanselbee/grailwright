# KS Addons

KS Addons is the companion-addon area inside Grailwright. It houses small
targeted plugins for other Tainted Grail: The Fall of Avalon mods.

Current addon folders:

- `KSWyrdSightAddon`
- `KSWyrdHuntAddon`
- `KSTGAllLightsCastShadowsAddon`
- `KSMoreWeaponLoadoutsAddon`

Original mod targets:

- Wyrd Sight Addon: for Wyrd Sight, which loads in BepInEx as plugin version
  1.1.1.
- Wyrd Hunt Addon 1.4.1: for Wyrd Hunt Nexus file Version 5, which loads in
  BepInEx as plugin version 0.4.65. Its Hunt Tuning Preset is a one-shot
  template selector: Default, Sparse, Stalker, and CursedNight write Wyrd
  Hunt's own hunt/threat settings, save them, then return the selector to
  Custom so manual edits remain active.
- TG All Lights Cast Shadows Addon: for TG All Lights Cast Shadows Mono file
  1.0.0-mono, which loads in BepInEx as plugin version 1.2.0.
- More Weapon Loadouts Addon: for Owrocc HUD Tweaks / More Weapon Loadouts 1.5.0,
  from Owrocc HUD Tweaks file 60.2.

The imported source versions may be newer than the original suite description
line when an addon has received a follow-up update.

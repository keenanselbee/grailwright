[center][color=#C94A4A][size=6]KS Addons[/size][/color]
[i]Companion addons for selected Tainted Grail: The Fall of Avalon mods.[/i][/center]

[line]

[b]KS Addons[/b] gathers focused companion plugins that run alongside selected [b]Tainted Grail: The Fall of Avalon[/b] mods.

Each addon has its own folder and README. Install only the addons whose original mods you use.

[heading][color=#C94A4A][size=5]KS Better Movement Addon[/size][/color][/heading]
Companion addon for Better Movement 1.3.0 or newer.

[list]
[*][b]Terrain-aware slide audio:[/b] Adds continuous audio to the original mod's slides, including extended downhill movement. Detects native terrain splatmaps, explicit mesh surfaces, and shallow water across eleven surface families.[/*]
[*][b]Seamless surface transitions:[/b] Crossfades when a slide reaches another surface and responds to sliding speed with configurable volume and pitch.[/*]
[*][b]Complete surface sound sets:[/b] Includes two loop, start, and stop variations for every supported surface.[/*]
[*][b]Positional custom audio:[/b] Uses 3D FMOD playback and supports replaceable WAV folders for custom sound packs.[/*]
[*][b]Immersive Footsteps compatibility:[/b] Keeps ordinary steps from [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/257]Immersive Footsteps[/url] separate from continuous slide-audio playback.[/*]
[/list]

[b]Audio source:[/b] Edited material from [url=https://www.asoundeffect.com/sound-library/footsteps-full-bundle/]Footsteps: Full Bundle[/url] by Sound Armoury / Matt J Hart, used under license.

Config file:

[code]
BepInEx/config/ks.tgfoa.better-movement-addon.cfg[/code]

Common entries:

[code]
Enabled = true
Volume = 0.4
MinimumSpeedVolumeScale = 0.55
PitchBySpeed = 0.12
CrossfadeSeconds = 0.1
Diagnostics = false[/code]

[heading][color=#C94A4A][size=5]Wyrd Sight Addon[/size][/color][/heading]
Companion addon for [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/94]Wyrd Sight[/url].

[list]
[*][b]Timed Wyrd Sight pulses:[/b] Changes the configured Highlight Key from a toggle into a timed pulse. Repeated presses extend the active pulse, and the addon only turns off pulses it started, leaving externally enabled Wyrd Sight active.[/*]
[*][b]Quest-giver highlighting:[/b] Adds optional, performance-friendly quest-giver outlines inspired by Avalon Untold. Avalon Untold is not required.[/*]
[*][b]Conservative availability checks:[/b] Hides progression-locked quest offers by default without incorrectly treating temporary conditions as permanent blockers.[/*]
[*][b]Configurable behavior:[/b] Pulse duration, state-check cadence, retry timing, retry limits, quest range, scan budgets, and outline refresh rates remain adjustable. For a clean pulse, use [b]Enable Glow Shape = true[/b] and [b]Enable Wyrd Sight Particles = false[/b] in Wyrd Sight.[/*]
[*][b]Bounded background work:[/b] Parses the story archive off the game thread, refreshes NPCs through events, spreads scans and outline baking across frames, and limits animated outline refreshes to 30 per second by default. Quest availability refreshes at each pulse and every 15 seconds only while Wyrd Sight remains continuously active.[/*]
[*][b]Clean disable and re-enable:[/b] Turning off Enabled or HighlightQuestGivers immediately removes listeners, cached outlines, and rendering resources. An archive read already in progress may finish and remain cached, preventing duplicate background parsing if the feature is re-enabled.[/*]
[/list]

Config file:

[code]
BepInEx/config/ks.tgfoa.wyrd-sight-addon.cfg[/code]

Common entries:

[code]
Enabled = true
PulseDurationSeconds = 3
PulseStateCheckIntervalSeconds = 0.25
OffRetryDelaySeconds = 0.25
MaximumOffAttempts = 3[/code]

Quest-giver entries:

[code]
HighlightQuestGivers = true
QuestGiverMode = Balanced
QuestGiverMaxDistance = 20
QuestScanFrameBudgetMilliseconds = 5
QuestOutlineBakeFrameBudgetMilliseconds = 1.5
QuestOutlineRefreshRate = 30
QuestAvailabilityRefreshSeconds = 15[/code]

[heading][color=#C94A4A][size=5]Persistent Corpses Addon[/size][/color][/heading]
Companion addon for [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/228]Persistent Corpses[/url].

[list]
[*][b]Smooth corpse restoration:[/b] Restored bodies can briefly appear standing and then fall over. The addon conceals them while ragdoll physics settles, then reveals them in a natural resting pose.[/*]
[*][b]Physics-aware settling:[/b] Settle time advances only during active physics, ignores loading screens and paused gameplay, and uses a maximum timeout for unstable bodies. Initialization scans stop once each corpse is ready.[/*]
[*][b]Limited retention (default):[/b] Keeps up to 10 loaded full corpses. Excess bodies use the game's native cleanup once they are distant enough, avoiding visible changes near the player.[/*]
[*][b]Alternative retention modes:[/b] [b]All[/b] preserves every corpse as before, while [b]Vanilla[/b] allows every eligible distant corpse to use normal cleanup.[/*]
[*][b]Safe long-rest cleanup:[/b] After a bonfire rest of at least six actual hours, empty loaded corpses are gradually removed and loot-bearing ones become lightweight replacement bodies. Visible loot is preserved, unsafe bodies remain untouched, and no additional save data is written.[/*]
[/list]

Config file:

[code]
BepInEx/config/ks.tgfoa.persistent-corpses-addon.cfg[/code]

Common entries:

[code]
Enabled = true
MinimumSettleSeconds = 0.75
MaximumSettleSeconds = 2
RetentionMode = Limited
MaximumLoadedFullCorpses = 10
CleanupAfterLongBonfireRest = true
MinimumRestHoursForCleanup = 6
Diagnostics = false[/code]

[heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with Vortex as [b]BepInEx plugins[/b], or place the selected addon folders under:

[code]
BepInEx/plugins/WyrdSightAddon/WyrdSightAddon.dll
BepInEx/plugins/TGAllLightsCastShadowsAddon/TGAllLightsCastShadowsAddon.dll
BepInEx/plugins/PersistentCorpsesAddon/PersistentCorpsesAddon.dll
BepInEx/plugins/BetterMovementAddon/BetterMovementAddon.dll[/code]

Keep each addon's original mod installed. All four addons declare hard dependencies, so they will not run without their original mods.

[line]

[heading][color=#C94A4A][size=5]Updating[/size][/color][/heading]
Each addon manages its own config and backups.

Incompatible config updates create a backup and generate current defaults. Some supported settings are automatically carried over.

FoA Mod Manager's final [b]Import Previous Settings[/b] tab shows the current and available backup schemas. Toggle the import action to restore compatible customized settings. Restart the game after importing.

[heading][color=#C94A4A][size=5]Version Safety[/size][/color][/heading]
These addons touch specific internals of their original mods. The listed original mod versions are the versions this bundle was built against and tested with.

Some Nexus file versions differ from the internal BepInEx plugin versions shown in the game log. When that happens, this page lists both labels.

Later original mod updates may make an addon unnecessary, partially incompatible, or fully incompatible. If an original mod updates, check its changelog, keep backups, and disable the matching addon if the original mod includes the same behavior natively or its internals change.

[center][color=#C94A4A][size=6]KS Addons[/size][/color]
[i]Companion addons for selected Tainted Grail: The Fall of Avalon mods.[/i][/center]

[line]

[b]KS Addons[/b] gathers focused companion plugins that run alongside selected [b]Tainted Grail: The Fall of Avalon[/b] mods.

Each addon has its own folder and README. Install only the addons whose original mods you use.

[heading][color=#C94A4A][size=5]KS Better Movement Addon[/size][/color][/heading]
Companion addon for Better Movement 1.3.0 or newer.

[list]
[*]Adds continuous terrain-aware audio to the original mod's slides, including extended downhill slides.[/*]
[*]Detects native terrain splatmaps, explicit mesh surfaces, and shallow water across eleven surface families.[/*]
[*]Crossfades when a slide moves onto another surface and responds to sliding speed with configurable volume and pitch.[/*]
[*]Includes two loop, start, and stop variations for every supported surface.[/*]
[*]Uses positional 3D FMOD playback and replaceable custom WAV folders.[/*]
[*]Remains compatible with [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/257]Immersive Footsteps[/url]; ordinary steps and continuous slide audio use separate playback routes.[/*]
[/list]

[b]Audio source:[/b] Edited material from [url=https://www.asoundeffect.com/sound-library/footsteps-full-bundle/]Footsteps: Full Bundle[/url] by Sound Armoury / Matt J Hart, used under license.

Config file:

[code]
BepInEx/config/ks.tgfoa.better-movement-addon.cfg[/code]

Common entries:

[code]
Enabled = true
Volume = 0.4
MinimumSpeedVolumeScale = 0.55
PitchBySpeed = 0.12
CrossfadeSeconds = 0.1
Diagnostics = false[/code]

[heading][color=#C94A4A][size=5]Wyrd Sight Addon[/size][/color][/heading]
Companion addon for [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/94]Wyrd Sight[/url].

[list]
[*]Turns Wyrd Sight's configured Highlight Key from a toggle into a timed pulse.[/*]
[*]Adds [b]Highlight Quest Givers[/b] with a performance-friendly implementation inspired by Avalon Untold; Avalon Untold is not required.[/*]
[*]Uses conservative quest-giver filtering by default, hiding progression-locked offers without treating temporary conditions as permanent blockers.[/*]
[*]Only turns off pulses the addon started, so externally enabled Wyrd Sight stays alone.[/*]
[*]Lets repeated key presses extend the current addon-owned pulse.[/*]
[*]Keeps pulse duration, state-check cadence, off-retry delay, and retry cap configurable in the addon's own config.[/*]
[*]For the clean pulse look, Wyrd Sight is best used with [b]Enable Glow Shape = true[/b] and [b]Enable Wyrd Sight Particles = false[/b].[/*]
[*]Parses the story archive off the game thread, uses event-driven NPC refreshes and frame-sliced scan work, and caps animated outline refreshes at 30 per second by default.[/*]
[*]Refreshes quest availability at each pulse and every 15 seconds only while Wyrd Sight remains continuously active.[/*]
[*]Setting Enabled or HighlightQuestGivers to false removes listeners, cached outlines, and render resources immediately. An already-started archive read may finish in the background and is retained so re-enabling cannot start a duplicate parse.[/*]
[/list]

Config file:

[code]
BepInEx/config/ks.tgfoa.wyrd-sight-addon.cfg[/code]

Common entries:

[code]
Enabled = true
PulseDurationSeconds = 3
PulseStateCheckIntervalSeconds = 0.25
OffRetryDelaySeconds = 0.25
MaximumOffAttempts = 3[/code]

Quest-giver entries:

[code]
HighlightQuestGivers = true
QuestGiverMode = Balanced
QuestGiverMaxDistance = 20
QuestScanFrameBudgetMilliseconds = 5
QuestOutlineBakeFrameBudgetMilliseconds = 1.5
QuestOutlineRefreshRate = 30
QuestAvailabilityRefreshSeconds = 15[/code]

[heading][color=#C94A4A][size=5]Persistent Corpses Addon[/size][/color][/heading]
Companion addon for [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/228]Persistent Corpses[/url].

[list]
[*]Normally, restored enemies can briefly appear in a standing T-pose and fall over after loading a save.[/*]
[*]This addon fixes that visible transition by concealing restored corpse renderers while ragdoll physics settles, then revealing each body in a natural resting pose.[/*]
[*]Counts only active physics time, so loading screens and paused gameplay do not consume the settle window.[/*]
[*]Uses a maximum timeout for bodies that continue moving on slopes.[/*]
[*]After a bonfire rest of at least three actual hours, gradually removes empty loaded corpses and converts loot-bearing ones to the game's lightweight replacement bodies.[/*]
[*]Preserves visible loot, leaves bodies that cannot be simplified safely untouched, and does not modify save data.[/*]
[*]Stops repeated hierarchy scans once each restored corpse finishes initializing.[/*]
[/list]

Config file:

[code]
BepInEx/config/ks.tgfoa.persistent-corpses-addon.cfg[/code]

Common entries:

[code]
Enabled = true
MinimumSettleSeconds = 0.75
MaximumSettleSeconds = 2
CleanupAfterLongBonfireRest = true
MinimumRestHoursForCleanup = 3
Diagnostics = false[/code]

[heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with Vortex as [b]BepInEx plugins[/b], or place the selected addon folders under:

[code]
BepInEx/plugins/WyrdSightAddon/WyrdSightAddon.dll
BepInEx/plugins/TGAllLightsCastShadowsAddon/TGAllLightsCastShadowsAddon.dll
BepInEx/plugins/PersistentCorpsesAddon/PersistentCorpsesAddon.dll
BepInEx/plugins/BetterMovementAddon/BetterMovementAddon.dll[/code]

Keep each addon's original mod installed. All four addons declare hard dependencies, so they will not run without their original mods.

[line]

[heading][color=#C94A4A][size=5]Updating[/size][/color][/heading]
Each addon manages its own config and backups.

Incompatible config updates create a backup and generate current defaults. Some supported settings are automatically carried over.

FoA Mod Manager's final [b]Import Previous Settings[/b] tab shows the current and available backup schemas. Toggle the import action to restore compatible customized settings. Restart the game after importing.

[heading][color=#C94A4A][size=5]Version Safety[/size][/color][/heading]
These addons touch specific internals of their original mods. The listed original mod versions are the versions this bundle was built against and tested with.

Some Nexus file versions differ from the internal BepInEx plugin versions shown in the game log. When that happens, this page lists both labels.

Later original mod updates may make an addon unnecessary, partially incompatible, or fully incompatible. If an original mod updates, check its changelog, keep backups, and disable the matching addon if the original mod includes the same behavior natively or its internals change.

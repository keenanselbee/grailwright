[center][color=#C94A4A][size=6]KS Addons[/size][/color]
[i]Companion addons for selected Tainted Grail: The Fall of Avalon mods.[/i][/center]

[line]

KS Addons is a small BepInEx 5 Mono collection for [b]Tainted Grail: The Fall of Avalon[/b]. It gathers focused companion plugins that run alongside the original mods they support.

Each addon has its own folder and README. Install only the addons whose original mods you use.

[heading][color=#C94A4A][size=5]Wyrd Sight Addon[/size][/color][/heading]
Companion addon for [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/94]Wyrd Sight[/url].

[list]
[*]Turns Wyrd Sight's configured Highlight Key from a toggle into a timed pulse.[/*]
[*]Only turns off pulses the addon started, so externally enabled Wyrd Sight stays alone.[/*]
[*]Lets repeated key presses extend the current addon-owned pulse.[/*]
[*]Keeps pulse duration, state-check cadence, off-retry delay, and retry cap configurable in the addon's own config.[/*]
[*]For the clean pulse look, Wyrd Sight is best used with [b]Enable Glow Shape = true[/b] and [b]Enable Wyrd Sight Particles = false[/b].[/*]
[/list]

Config file:

[code]
BepInEx/config/ks.tgfoa.wyrd-sight-addon.cfg[/code]

Version 1.0.3 appears as [b]Wyrd Sight Addon[/b] in BepInEx and Configuration Manager while keeping the same config path.

Common entries:

[code]
Enabled = true
PulseDurationSeconds = 3
PulseStateCheckIntervalSeconds = 0.25
OffRetryDelaySeconds = 0.25
MaximumOffAttempts = 3[/code]

[heading][color=#C94A4A][size=5]Wyrd Hunt Addon[/size][/color][/heading]
Companion addon for [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/201]Wyrd Hunt[/url].

[list]
[*]Adds Grail Floating Text Wyrd Scent status text with the shared Wyrd icon when Wyrd Hunt status changes.[/*]
[*]If Grail Floating Text is installed, the parent Wyrd Scent meter is hidden by default.[/*]
[*]Can alternatively keep the parent meter and hide it only while safe or during title, loading, startup, and portal transitions.[/*]
[*]Keeps the Wyrd Scent meter position configurable with horizontal and bottom offsets.[/*]
[*]Adds weighted random Wyrd Hunt spawns from whitelisted native enemy templates.[/*]
[*]Adds optional mixed hunt packs with rare extra same-or-lower-tier pack mates beside the primary hunt target.[/*]
[*]Favors weaker sidecars, reduces same-tier and same-family picks, and treats Wyrdspirit as a prioritized 1-4 spirit sidecar cluster.[/*]
[*]Adds one-shot tuning presets for rarer, more focused hunts without locking manual settings.[/*]
[*]Avoids immediate repeat hunts by default when another valid monster is available.[/*]
[*]Includes optional hard hunt pools, disabled by default.[/*]
[/list]

Config file:

[code]
BepInEx/config/ks.tgfoa.wyrd-hunt-addon.cfg[/code]

Common entries:

[code]
Hunt Tuning Preset = Custom
Scent Meter Mode = NotificationsOnly
Notifications Enabled = true
Notification Text Format = Wyrd Scent: {stage}
Show Scent Number = false
Hide When Safe From Wyrdness = true
Hide On Loading Screens = true
Bottom Offset = 205
Enable Randomized Spawns = true
Auto Profile Only = true
Preserve Wyrdspirit Stalking = true
Enable Hard Hunts = false
Avoid Immediate Repeats = true
Enable Mixed Hunt Packs = true
Two Enemy Pack Chance Percent = 18
Three Enemy Pack Chance Percent = 3
Wyrdspirit Sidecar Weight = 80
Wyrdspirit Max Pack Count = 4
Same Tier Pack Mate Weight Percent = 25
Same Family Pack Mate Weight Percent = 35[/code]

Preset behavior is one-shot. [b]Hunt Tuning Preset[/b] defaults to [b]Custom[/b]. Selecting [b]Default[/b], [b]Sparse[/b], [b]Stalker[/b], or [b]CursedNight[/b] immediately writes Wyrd Hunt's own hunt/threat settings in [b]kane.tgfoa.wyrd-hunt.cfg[/b], saves them, records [b]Last Applied Hunt Tuning Preset[/b], and returns the selector to [b]Custom[/b]. After that, individual Wyrd Hunt settings remain editable.

[b]Sparse[/b] makes hunts rare and calmer. [b]Stalker[/b] is the recommended rare-but-tense profile. [b]CursedNight[/b] keeps nights dangerous while still capping scene/session pressure. [b]Default[/b] restores Wyrd Hunt's original tuning.

Weights live under [b]Weights.Contact[/b], [b]Weights.Stalking[/b], [b]Weights.Hunter[/b], [b]Weights.Pursuit[/b], and [b]Weights.Marked[/b]. Set a weight to [b]0[/b] to disable that entry.

Grail Floating Text is an optional soft requirement for visible Wyrd Hunt Addon status text. If Grail Floating Text is installed, the parent Wyrd Scent meter is hidden by default.

[heading][color=#C94A4A][size=5]More Weapon Loadouts Addon[/size][/color][/heading]
Companion addon for [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/192]Owrocc HUD Tweaks / More Weapon Loadouts[/url].

[list]
[*]Handles saves that contain duplicate [b]VirtualLoadouts.json[/b] entries by preferring the useful/latest entry instead of a stale empty one.[/*]
[*]Helps prevent More Weapon Loadouts slot 1 from loading as unbound and falling back to fists.[/*]
[*]Redirects vanilla gameplay weapon loadout keys to More Weapon Loadouts virtual slots by default.[/*]
[*]Coordinates shared number-row shortcuts so the same slot is not activated twice.[/*]
[*]Can refresh More Weapon Loadouts' auto-track baseline shortly after loading a save.[/*]
[/list]

Config file:

[code]
BepInEx/config/ks.tgfoa.more-weapon-loadouts-addon.cfg[/code]

Common entries:

[code]
FixDuplicateVirtualLoadoutEntries = true
RedirectVanillaWeaponLoadoutKeys = true
ReprimeAutoTrackAfterLoad = true
ReapplyCurrentVirtualSlotAfterLoad = false[/code]

Only enable [b]ReapplyCurrentVirtualSlotAfterLoad[/b] if slot 1 still comes back visually wrong after loading.

[heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with Vortex as [b]BepInEx plugins[/b], or place the selected addon folders under:

[code]
BepInEx/plugins/WyrdSightAddon/WyrdSightAddon.dll
BepInEx/plugins/WyrdHuntAddon/WyrdHuntAddon.dll
BepInEx/plugins/TGAllLightsCastShadowsAddon/TGAllLightsCastShadowsAddon.dll
BepInEx/plugins/MoreWeaponLoadoutsAddon/MoreWeaponLoadoutsAddon.dll[/code]

Keep each addon's original mod installed. Wyrd Sight Addon, Wyrd Hunt Addon, and TG All Lights Cast Shadows Addon declare hard dependencies, so they will not run without their original mods. Wyrd Hunt Addon also declares Grail Floating Text as a soft dependency for shared status text. More Weapon Loadouts Addon uses a soft dependency and simply leaves its redirect inactive if More Weapon Loadouts is missing.

[heading][color=#C94A4A][size=5]Version Safety[/size][/color][/heading]
These addons touch specific internals of their original mods. The listed original mod versions are the versions this bundle was built against and tested with.

Some Nexus file versions differ from the internal BepInEx plugin versions shown in the game log. When that happens, this page lists both labels.

Later original mod updates may make an addon unnecessary, partially incompatible, or fully incompatible. If an original mod updates, check its changelog, keep backups, and disable the matching addon if the original mod includes the same behavior natively or its internals change.

[line]

[heading][color=#C94A4A][size=5]Note To Mod Authors[/size][/color][/heading]
If one of these addons touches your mod, you are welcome to incorporate the behavior upstream if you wish. These companion addons exist to solve local compatibility and tuning issues quickly, not to compete with or replace the original mods.

[i]Companion addons for selected Tainted Grail: The Fall of Avalon mods.[/i][/center]

[line]

[b]KS Addons[/b] gathers focused companion plugins that run alongside selected [b]Tainted Grail: The Fall of Avalon[/b] mods.

Each addon has its own folder and README. Install only the addons whose original mods you use.

[heading][color=#C94A4A][size=5]All Lights Cast Shadows Addon[/size][/color][/heading]
Companion addon for [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/133]All Lights Cast Shadows[/url].

[list]
[*][b]Reliable restoration:[/b] Restores the game's original shadow quality and each light's original shadow settings when it no longer needs protection or either mod is disabled.[/*]
[*][b]Firelight protection:[/b] Prevents bonfire, campfire, and optional user-added lights from being blocked by nearby firepit stones.[/*]
[*][b]Safer shadow limits:[/b] Gives lights upgraded by the original mod a safe 256 shadow-resolution limit by default without raising lights that already use a lower value.[/*]
[*][b]Combat performance:[/b] Lowers the shadow limit to 128 during outdoor fights, then restores it five seconds after combat. Optional controls can also reduce the number or range of upgraded lights.[/*]
[*][b]Clean integration and feedback:[/b] Works through the original mod's own scans, adds no constant light search, and never changes its JSON file. Grail Floating Text can confirm actual parent toggle changes independently. Diagnostics keeps detailed log counts, while the default-on ShowGrailFloatingTextDiagnostics switch controls in-game shadow summaries and remains inactive unless Diagnostics is enabled.[/*]
[/list]

Config file:

[code]
BepInEx/config/ks.tgfoa.tg-all-lights-cast-shadows-addon.cfg[/code]

[heading][color=#C94A4A][size=5]KS Better Movement Addon[/size][/color][/heading]
Companion addon for Better Movement 1.3.0 or newer.

[list]
[*][b]Terrain-aware slide sounds:[/b] Adds continuous audio to slides, including extended downhill movement. Recognizes terrain, constructed floors, and shallow water across eleven surface families.[/*]
[*][b]Smooth surface changes:[/b] Crossfades when a slide reaches a different surface and adjusts volume and pitch with sliding speed.[/*]
[*][b]Complete sound sets:[/b] Includes two slide loops plus start and stop variations for every supported surface.[/*]
[*][b]3D and custom audio:[/b] Plays sounds from the player's position and supports replaceable WAV folders for custom sound packs.[/*]
[*][b]Immersive Footsteps compatibility:[/b] Keeps ordinary steps from [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/257]Immersive Footsteps[/url] separate from continuous slide-audio playback.[/*]
[/list]

[b]Audio source:[/b] Edited material from [url=https://www.asoundeffect.com/sound-library/footsteps-full-bundle/]Footsteps: Full Bundle[/url] by Sound Armoury / Matt J Hart, used under license.

Config file:

[code]
BepInEx/config/ks.tgfoa.better-movement-addon.cfg[/code]

[*][b]Clean parent integration and feedback:[/b] Keeps the original hotkey and JSON reload behavior, never edits TGVolumetricFix.json, and allows optional global operation or higher quality through this addon's config. [heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with Vortex as [b]BepInEx plugins[/b], or place the selected addon folders under:

[code]
BepInEx/plugins/TGAllLightsCastShadowsAddon/TGAllLightsCastShadowsAddon.dll
BepInEx/plugins/BetterMovementAddon/BetterMovementAddon.dll
BepInEx/plugins/TGVolumetricFixAddon/TGVolumetricFixAddon.dll
BepInEx/plugins/TGContactShadowsAddon/TGContactShadowsAddon.dll
BepInEx/plugins/TGGlobalIlluminationAddon/TGGlobalIlluminationAddon.dll
BepInEx/plugins/PersistentCorpsesAddon/PersistentCorpsesAddon.dll
BepInEx/plugins/WyrdSightAddon/WyrdSightAddon.dll[/code]

Keep each addon's original mod installed. All seven addons declare hard dependencies, so they will not run without their original mods.

[heading][color=#C94A4A][size=5]Updating[/size][/color][/heading]
Each addon manages its own config and backups.

Incompatible config updates create a backup and generate current defaults. Some supported settings are automatically carried over.

FoA Mod Manager's final [b]Import Previous Settings[/b] tab shows the current and available backup schemas. Toggle the import action to restore compatible customized settings. Restart the game after importing.

[heading][color=#C94A4A][size=5]Version Safety[/size][/color][/heading]
These addons touch specific internals of their original mods. The listed original mod versions are the versions this bundle was built against and tested with.

Some Nexus file versions differ from the internal BepInEx plugin versions shown in the game log. When that happens, this page lists both labels.

Later original mod updates may make an addon unnecessary, partially incompatible, or fully incompatible. If an original mod updates, check its changelog, keep backups, and disable the matching addon if the original mod includes the same behavior natively or its internals change.

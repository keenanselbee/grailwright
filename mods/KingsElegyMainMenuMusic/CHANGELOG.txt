Version 2.0.0
Added MusicMode with LayeredModifiedTaintedGrail, CustomFile, and Off modes.
Made LayeredModifiedTaintedGrail the default mode, using separate base title music, fire ambience, and wind ambience WAV layers.
Applied the approved DSP profile to the base title music layer only: -9 semitones, 4096 FFT size, 32 overlap, high-frequency restore EQ, 0.1 distortion, 5500 Hz lowpass, and short quiet echo at 100 ms / 10% / -36 dB.
Kept fire and wind ambience unpitched, with independent toggles and volume controls.
Renamed the built-in layered audio files to menu_layer_01.ksaudio, menu_layer_02.ksaudio, and menu_layer_03.ksaudio while keeping valid WAV data inside each file.
Kept main_menu_music.wav as a raw CustomFile option with shared loop start, end trim, and crossfade controls, but no layered ambience or DSP effects.
Replaced bundled main_menu_music.wav with a small silent PCM placeholder so CustomFile mode is safe by default until users add their own track.
Normalized the built-in layered fire and wind WAVs to match the base title music sample rate: stereo 44.1 kHz 16-bit PCM.
Added FadeOutOnGameLoad and GameLoadFadeSeconds so replacement title music fades out during real game loading, then muted original title emitters are stopped/restored silently instead of faded back into loading.
Made live effect config changes reconfigure the active base music DSP where possible instead of restarting playback.
Added Harmony hooks for NewGameLoading, NewGamePlusLoading, FullLoading, and MapChangeLoading load transitions.
Bumped ConfigSchemaVersion to 8 so older configs are backed up and regenerated with the new default layer filenames.

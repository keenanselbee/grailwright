[center][color=#C94A4A][size=6]King's Elegy - Main Menu Music[/size][/color]
[i]Layered, configurable title-screen music with fire, wind, and custom WAV support.[/i][/center]

[line]

[b]King's Elegy - Main Menu Music[/b] gives you full control over the title-screen music route, from its layered default arrangement to a completely custom WAV.

By default, it now builds a layered version of the Tainted Grail title music from separate music, fire, and wind WAV files. The main music layer is lowered and treated with a subtle demonic FMOD DSP chain, while the fire and wind ambience stay unpitched so they keep their natural crackle and movement.

[b]main_menu_music.wav[/b] is included as a small silent placeholder for the raw custom-track option. Replace it with your own WAV if you use [b]MusicMode = CustomFile[/b]. CustomFile still uses loop start, end trim, and crossfade settings, but it is not affected by pitch, demonic effects, fire ambience, wind ambience, or layered title music settings.

[heading][color=#C94A4A][size=5]Features[/size][/color][/heading]
[list]
[*][b]Layered default score:[/b] Build the title music from separate music, fire, and wind WAV layers with independent ambience controls.[/*]
[*][b]Demonic music treatment:[/b] Apply pitch and FMOD DSP effects to the base music layer without distorting the natural fire and wind ambience.[/*]
[*][b]Custom WAV mode:[/b] Replace the soundtrack with your own raw WAV while retaining loop trim and crossfade controls.[/*]
[*][b]Clean title routing:[/b] Mute the original emitters while replacement music is active and prevent title audio from bleeding into loading or gameplay.[/*]
[*][b]Polished transitions:[/b] Use configurable loop trimming, optional soft crossfades, and a fade-out when a real game load begins.[/*]
[*][b]Non-destructive operation:[/b] Leave FMOD banks and game files untouched.[/*]
[/list]

[line]

[heading][color=#C94A4A][size=5]Default Base Music[/size][/color][/heading]
[center][youtube]JZh5Ne4cCs0[/youtube][/center]

[code]
MusicMode = LayeredModifiedTaintedGrail
Semitones = -7
BaseMusicVolume = 1.0
ApplyEffectsToBaseMusic = true
BaseMusicFile = menu_layer_01.ksaudio[/code]

[line]

[heading][color=#C94A4A][size=5]Default Ambience Layers[/size][/color][/heading]
[code]
EnableFireAmbience = true
FireAmbienceVolume = 1.0
FireAmbienceFile = menu_layer_02.ksaudio

EnableWindAmbience = true
WindAmbienceVolume = 1.0
WindAmbienceFile = menu_layer_03.ksaudio[/code]

Music volume settings are relative mix controls. The default value of 1.0 now plays at the previous 0.2 FMOD volume baseline.

The three built-in layered files are stereo 44.1 kHz 16-bit PCM files with WAV data and matching duration for synchronized playback.

[line]

[heading][color=#C94A4A][size=5]Advanced DSP Defaults[/size][/color][/heading]
These effects apply only to the base Tainted Grail title music layer:

[code]
FFTSize = 4096
Overlap = 32

EnableHighFrequencyRestore = true
HighFrequencyGainDb = 1.5
HighFrequencyCrossoverHz = 5000

DemonicMode = true
EnableDistortion = true
DistortionLevel = 0.1
EnableLowpass = true
LowpassCutoffHz = 5500
EnableEcho = true
EchoDelayMs = 100
EchoFeedbackPercent = 10
EchoWetLevelDb = -36[/code]

[line]

[heading][color=#C94A4A][size=5]Custom Music[/size][/color][/heading]
To use your own replacement WAV:

[code]
MusicMode = CustomFile
CustomMusicFile = main_menu_music.wav
CustomMusicVolume = 1.0[/code]

CustomFile mode plays the configured file as-is. The packaged [b]main_menu_music.wav[/b] is a silent placeholder, so replace it with your own WAV before using this mode. It still uses loop start, end trim, and crossfade settings, but it does not receive the layered title music effects or ambience layers.

[line]

[heading][color=#C94A4A][size=5]Loading Fade[/size][/color][/heading]
[code]
FadeOutOnGameLoad = true
GameLoadFadeSeconds = 10[/code]

The plugin patches real game-loading operations and fades replacement title music out when gameplay/loading starts. After the replacement fades out, muted original title emitters are stopped and restored silently so title music does not continue into loading or gameplay.

[line]

[heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with a mod manager or place the plugin folder under [b]BepInEx\plugins[/b]:

[code]
BepInEx/plugins/KingsElegyMainMenuMusic/MainMenuMusic.dll
BepInEx/plugins/KingsElegyMainMenuMusic/audio/menu_layer_01.ksaudio
BepInEx/plugins/KingsElegyMainMenuMusic/audio/menu_layer_02.ksaudio
BepInEx/plugins/KingsElegyMainMenuMusic/audio/menu_layer_03.ksaudio
BepInEx/plugins/KingsElegyMainMenuMusic/main_menu_music.wav[/code]

[line]

[heading][color=#C94A4A][size=5]Updating[/size][/color][/heading]
Incompatible config updates create a backup and generate current defaults. Some supported settings are automatically carried over.

FoA Mod Manager's final [b]Import Previous Settings[/b] tab shows the current and available backup schemas. Toggle the import action to restore compatible customized settings. Restart the game after importing.

[line]

[heading][color=#C94A4A][size=5]Configuration[/size][/color][/heading]
The config is generated after first launch:

[code]
BepInEx/config/ks.tgfoa.main-menu-music.cfg[/code]

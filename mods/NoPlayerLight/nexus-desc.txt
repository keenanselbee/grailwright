[center][color=#C94A4A][size=6]No Player Light[/size][/color]
[i]Let caves, nights, torches, and lanterns carry the scene.[/i][/center]

[line]

No Player Light removes the hidden player-centered [b]HeroLight[/b] from [b]Tainted Grail: The Fall of Avalon[/b]. The goal is darker, more natural lighting without the constant artificial glow around the player.

Torches, lanterns, interiors, nights, caves, ReShade presets, and lighting mods get more room to define the scene. Only the hidden player light is affected; world lights, wall torches, bonfires, NPC lights, shadows, weather, and post-processing are left alone.

[line]

[heading][color=#C94A4A][size=5]What It Does[/size][/color][/heading]
[list]
[*]Disables the game's hidden [b]HeroLight[/b] object when it appears by default.[/*]
[*]Adds [b]DisableHeroLight[/b] under [b]1. Core[/b] so the player light can be enabled or disabled from the generated BepInEx config.[/*]
[*]Runs on startup, after scene loads, and during a few delayed scene-load retries.[/*]
[*]Caches the found object so it can quickly disable it again if the game reactivates it.[/*]
[*]Uses a slow fallback scan in case the game creates a replacement later.[/*]
[*]Version 1.2.1 keeps the diagnostic HeroLight logging, moves DisableHeroLight into 1. Core, and has a plugin version higher than the old KS No Player Light 1.1.0 package.[/*]
[*]Does not edit game files, bundles, scenes, lights, or post-processing assets.[/*]
[/list]

[line]

[heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with Vortex as a [b]BepInEx plugin[/b], or place the plugin folder here:

[code]
BepInEx/plugins/NoPlayerLight/NoPlayerLight.dll[/code]

If upgrading from KS No Player Light, disable or remove the old KSNoPlayerLight package before enabling this one. They use the same BepInEx plugin GUID.

The diagnostic toggle is generated after first load:

[code]
BepInEx/config/ks.tgfoa.no-player-light.cfg

[1. Core]
ConfigSchemaVersion = 3
DisableHeroLight = true

[Diagnostics]
EnableRuntimeScan = true[/code]

[heading][color=#C94A4A][size=5]Notes[/size][/color][/heading]
This mod is intentionally small. If an area becomes too dark, use a torch, lantern, ReShade adjustment, or lighting mod rather than expecting No Player Light to rebalance the scene. It only removes the player-centered helper light.

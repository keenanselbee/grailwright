0.3.8
-----
- Tripled Soul Salvage's heavy-cast mana stat so the item card and actual charged
  cost agree, including the spell's normal item-level scaling.
- Replaced fixed 50% starting health and a 120-second timeout with full-health
  servants whose borrowed life drains by both a percentage and a flat amount.
  Defaults give a 200-health ordinary enemy about three minutes, guarantee at least
  90 seconds from decay alone, and let stronger enemies naturally last longer;
  combat damage can still kill any servant sooner.
- Removed raised-NPC health regeneration and route terminal decay through the native
  death sequence so summon cleanup and source-corpse restoration remain intact.
- Replaced Soul Salvage's stale vanilla light- and heavy-cast descriptions with live
  text that reflects the configured return mode, decay model, minimum, and permanence.
- Confirmed raised copies use the native hero-summon owner, ally faction, autonomous
  target acquisition, and enemy-hostility behavior without a separate aggro patch.
- Incremented the config schema because ReanimationDurationSeconds and
  ReanimationHealthPercent were removed and replaced by minimum-lifetime,
  percentage-decay, and flat-decay settings with new behavior.

0.3.7
-----
- Added concise Grail Floating Text diagnostics for Soul Salvage heavy-cast
  rejections, full servant limits, successful temporary or permanent raises,
  portrait fallbacks, unexpected failures, and source-corpse restoration.
- Added ShowGrailFloatingTextDiagnostics, enabled by default under the master
  Diagnostics setting, while retaining detailed decisions in the BepInEx log.
- Kept the config schema unchanged because adding a new setting lets Config.Bind
  supply its current default without resetting existing settings.

0.3.6
-----
- Preserved each raised servant's native NPC portrait when its Addressables reference is valid.
- Assigned the vanilla skeleton-summon spell portrait only when a copied corpse has no configured NPC icon, preventing the summon HUD from requesting an empty Sprite key.
- Kept the config schema unchanged because no setting or stored value changed.

0.3.5
-----
- Added explicit semantic section and setting order metadata for a cleaner FoA Mod Manager layout.
- Kept the config schema unchanged because stored section names, keys, types, meanings, and defaults are unchanged.

0.3.4
-----
- Limited the faster AI decision interval to hero summons; unrelated NPC allies now
  retain the native 2.5-second interval.
- Made target sharing use the game's own NPC accept/prevent masks across the full
  configured range, including obstruction handling beyond the native 20 m cache.
- Reworked Invocation of Might repair around the exact native replacement event.
  The outgoing summon must prove that scaling is active, and only missing scaling
  is added to the incoming summon, including when SummonLimitBonus is in use.
- Matched the game's collider-to-location lookup for Soul Salvage and restricted
  reanimation to runtime-spawned ordinary hostiles, rejecting authored scene and
  persistent NPC locations before cloning their templates.
- Incremented the config schema because every section was renamed to remove numeric
  prefixes and follow the current FoA Mod Manager ordering contract.

0.3.1
-----
- Made heavy Soul Salvage exclusively use the corpse-reanimation path instead of
  retaining the vanilla heavy summon-sacrifice effect.
- Required an unobstructed corpse target and added conservative protection for
  named, scripted, quest, merchant, guard, companion, boss, and friendly corpses.
- Marked raised summon elements as unsaved, tightened raised-copy cleanup, and
  restored source corpses during plugin shutdown.
- Limited magic-gauntlet pass-through to hero-owned attacks and reduced collision
  refresh overhead without changing runtime config responsiveness.

0.3.0
-----
- Added responsive hero-summon AI, close-follow thresholds, native safe catch-up
  teleporting, and an out-of-combat catch-up speed multiplier.
- Added conservative crosshair target sharing that preserves existing targets and
  native attacker sharing.
- Added Summon Pass-Through for hero body collision without disabling summon combat
  colliders or world collision.
- Added independent Vanilla, MagicOnly, and AllProjectiles player-attack pass-through
  modes; MagicOnly is the default.
- Added rest persistence, a configurable summon-limit bonus, replacement-summon
  Invocation of Might scaling repair, and percentage-based idle-loop volume.
- Repurposed Soul Salvage light cast into a health-scaled essence sacrifice with
  configurable Health, Mana, or Split returns.
- Repurposed Soul Salvage heavy cast to raise strictly filtered ordinary hostile
  corpses as unsaved hero-owned copies with restored source corpses, no XP, and no
  scripted death rewards.
- Added optional PermanentReanimations, disabled by default. Permanent servants have
  no duration for the current play session but never revive original persistent NPCs.
- Declared hard incompatibility with Avalon Summons, Better Summon, and the temporary
  Summon Pass-Through test plugin to prevent overlapping Harmony ownership.

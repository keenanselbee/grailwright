[center][color=#C94A4A][size=6]Wyrdsoul Reserve[/size][/color]
[i]Store a second bar of Wyrd Power in three visible overflow diamonds.[/i][/center]

[line]

[b]Wyrdsoul Reserve[/b] adds three diamond-shaped overflow vessels beside the Wyrd Power indicator without replacing the vanilla resource.

Each diamond holds one third of the main bar. Together, the vanilla bar and all three reserves provide 200% total Wyrd Power capacity.

[line]

[heading][color=#C94A4A][size=5]How It Works[/size][/color][/heading]
[list]
[*]Wyrd Power gained through gameplay fills the main bar first.[/*]
[*]Overflow fills the lower-left reserve first, then climbs toward the upper-right.[/*]
[*]The upper-right-most reserve containing charge drains first.[/*]
[*]Reserves cannot be activated or spent directly.[/*]
[*]After Wyrd Power becomes inactive and the configured delay passes, stored energy pours back into the main bar.[/*]
[*]Transfer pauses while Wyrd Power is active, making full diamonds additional activations instead of one extended activation.[/*]
[*]Manually cancelling Wyrd Power preserves the charge left in the main bar.[/*]
[*]Every activation costs 3% of the main bar by default, limiting free repeated activation effects without a large initial drop.[/*]
[/list]

[line]

[heading][color=#C94A4A][size=5]Passive Regeneration[/size][/color][/heading]
Wyrdsoul Reserve includes a deliberately slow gameplay-time trickle. By default, passive regeneration produces one complete main bar over 20 minutes of active gameplay. A native Wyrd night multiplies that rate by 3.

Passive energy fills the main bar first and then flows into the reserves. Paused menus, loading screens, and time outside live gameplay do not regenerate charge. There is no offline catch-up.

[line]

[heading][color=#C94A4A][size=5]HUD And Saving[/size][/color][/heading]
The reserve group is attached beneath the live vanilla Wyrd indicator. When [url=https://www.nexusmods.com/taintedgrailthefallofavalon/mods/248]Glorious UI[/url] owns that indicator, the reserves inherit its screen anchor, position, scale, fade, and reconstruction without moving Glorious UI's frame.

Each diamond uses ten transparent PNG states from empty to full. The included frame set can be replaced while retaining the same filenames:

[code]
BepInEx/plugins/WyrdsoulReserve/reserve-icons/reserve-0.png
through
BepInEx/plugins/WyrdsoulReserve/reserve-icons/reserve-9.png
[/code]

Reserve charge is stored inside each game save. Loading a save with Wyrdsoul Reserve data restores that save's recorded charge. Saves without Wyrdsoul Reserve data begin empty.

[line]

[heading][color=#C94A4A][size=5]Configuration[/size][/color][/heading]
Start the game once to generate:

[code]
BepInEx/config/ks.tgfoa.wyrdsoul-reserve.cfg
[/code]

[code]
| Setting                           | Default | Purpose                                      |
|-----------------------------------|---------|----------------------------------------------|
| Enabled                           | true    | Master switch                                |
| ActivationCostPercent             | 3       | Main-bar charge spent on each activation     |
| RechargeDelaySeconds              | 5       | Inactive delay before transfer or generation |
| PassiveFullRechargeMinutes        | 20      | Time to generate one complete main bar       |
| WyrdNightRegenerationMultiplier   | 3       | Passive rate during a native Wyrd night      |
| ReserveGainEfficiencyPercent      | 100     | Overflow and passive energy retained         |
| TransferSecondsPerReserve         | 0.75    | Time for one full diamond to pour back       |
| ReserveOffsetX                    | 0       | Horizontal HUD adjustment                    |
| ReserveOffsetY                    | 0       | Vertical HUD adjustment                      |
| ReserveScale                      | 1       | Scale of the complete reserve group          |
| ReserveIconSize                   | 42      | Square size of each diamond in pixels        |
| Diagnostics                       | false   | Detailed runtime logging                     |
[/code]

[line]

[heading][color=#C94A4A][size=5]Install[/size][/color][/heading]
Install with Vortex as a [b]BepInEx plugin[/b], or place the complete plugin folder here:

[code]
BepInEx/plugins/WyrdsoulReserve/WyrdsoulReserve.dll
[/code]

Keep the packaged [b]reserve-icons[/b] folder beside the DLL.

[line]

[heading][color=#C94A4A][size=5]Updating[/size][/color][/heading]
Incompatible config updates create a backup and generate current defaults. Some supported settings are automatically carried over.

FoA Mod Manager's final [b]Import Previous Settings[/b] tab shows the current and available backup schemas. Toggle the import action to restore compatible customized settings. Restart the game after importing.

Automatically preserved: Enabled, all resource tuning, all HUD layout settings, and Diagnostics.

[heading][color=#C94A4A][size=5]Troubleshooting[/size][/color][/heading]
If the diamonds are missing, verify that all ten reserve PNGs are installed beside [b]WyrdsoulReserve.dll[/b] and inspect [b]BepInEx/LogOutput.log[/b]. HUD position, scale, and icon size can be adjusted without changing Glorious UI's settings.

Enable [b]Diagnostics[/b] only while tracing overflow, transfer, passive regeneration, HUD attachment, or save behavior.
